# Current asset manifest

Updated 2026-10-20 for the simplified storefront. All runtime assets are local in `packages/storefront-ui/assets/`.

| File | Source and use |
| --- | --- |
| `smile-dog.svg`, `russian-sleep-experiment.svg`, `captain-clark.svg` | Plain text placeholders, no character illustration or shirt design. Not final merchandise artwork. |
| `oswald.ttf`, `OSWALD-LICENSE.txt` | [Google Fonts Oswald](https://github.com/google/fonts/tree/main/ofl/oswald), SIL Open Font License; wordmark only. |
| `tinos-regular.ttf`, `TINOS-LICENSE.txt` | [Google Fonts Tinos](https://github.com/google/fonts/tree/main/ofl/tinos) and [upstream license](https://github.com/googlefonts/tinos/blob/3b4482a99b80ea5fc75f187b1be3120a3f5905b3/OFL.txt); serif interface type. |
| `icon.svg` | Existing simple geometric V favicon. |
| `signal.svg` | Legacy geometric SVG; unused by the demo. |

The generated PNGs and Bodoni fonts were removed from the package and build. No third-party Creepypasta artwork or Isolation Man artwork is copied. Historical research, prompts, and evidence in this documentation folder describe an earlier direction and are not part of the deployed site.

The current font direction is Oswald for VULGAR and a traditional serif matching the user’s screenshot for everything else. Pixelify Sans was removed. The updated art direction permits AI-generated shirt designs and garment mockups only. User-provided references are retained locally in `docs/brand/references/`, outside the runtime assets. The later Astra task is recorded in `ASTRA_SHIRT_BRIEF.md`.
