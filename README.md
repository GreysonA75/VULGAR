# VULGAR storefront demo

A standalone React storefront demo with home, shop, product, bag, collection,
archive, and about pages. Includes shareable URLs, browser history, a persistent
bag, stock limits, and responsive layouts.

Products, artwork, prices, and releases are concept content. Checkout is unavailable.

See [local setup and integration](packages/storefront-ui/README.md).

For hosting, select Settings → Pages → GitHub Actions. Pushing to main runs
**Publish VULGAR demo**; it can also be run manually from the Actions tab.
